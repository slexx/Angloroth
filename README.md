# Angloroth

Selected Windows releases of Angloroth, shared here for easy downloading.

**[View shared releases and downloads](https://github.com/slexx/Angloroth/releases)**

No versions have been shared on this page yet. Releases appear here only when selected for sharing.

## Download and run

1. Open **Releases** and choose a version.
2. Download the **Angloroth-v…-windows-x64.zip** asset, then extract the entire folder.
3. Run **Angloroth.exe** and keep the extracted folder contents together.

The automatically generated “Source code” archives are not the Windows app. Choose the named Windows ZIP asset instead.

Each shared release includes release notes and a SHA-256 checksum for its ZIP. Follow the README included in the download for setup and controls.

## Updating

Close Angloroth before replacing application files. Keep your existing `data` folder to retain settings, teaching and run totals. Shared downloads do not contain another person's settings or recordings.

## About this page

This is the public distribution home for hand-picked releases. Application development and source history are maintained separately. Publishing a development build does not automatically publish it here.
