# Angloroth

Selected Windows releases of Angloroth, shared here for easy downloading.

## Current shared version: 0.9.0

**[Download Angloroth 0.9.0 for Windows x64](https://github.com/slexx/Angloroth/releases/tag/v0.9.0)**

This version includes point-and-capture bobber teaching, a persistent appearance library, guarded learning from loot-confirmed catches, and stopped-state library controls.

## Download and run

1. Open the release above and download **Angloroth-v0.9.0-windows-x64.zip**.
2. Extract the complete **Angloroth** folder.
3. Run **Angloroth.exe** and keep the extracted folder contents together. Python is not required.
4. Follow the included README to install Fishing State Checker, select the fishing area and teach a bobber. Start with Dry run enabled and a capture rate of **20 FPS**.

**F7** captures teaching for review. **F8** starts/stops fishing. **F9/Escape** stops it. The app always opens stopped.

The automatically generated “Source code” archives contain this distribution page, not the Windows app. Choose the named Windows ZIP asset instead.

Each shared release includes release notes and a SHA-256 checksum for its ZIP.

## Updating and privacy

Close Angloroth before replacing application files. Keep your existing `data` folder to retain settings, teaching, library and run totals. Shared downloads do not contain another person's settings, images, recordings or logs. The app makes no automatic uploads.

## Current limitations

Some brief or blue-tinted splashes can still be missed, including at 20 FPS. The library helps choose useful bobber appearances; it does not guarantee every catch. Reflections, obstructions and other identical bobbers can confuse image detection. Read the included README before using automatic input.

Automatic play can violate the game's rules and lead to account penalties. Screen-only operation does not establish permission or prevent detection.
