# Angloroth

Selected Windows releases of Angloroth, shared here for easy downloading.

## Current shared version — Sord 2.0.1

**[Download Angloroth Sord 2.0.1 for Windows x64](https://github.com/slexx/Angloroth/releases/tag/v2.0.1)**

Angloroth listens for bites in WoW Forever, uses the Better Fishing key to cast and reel, and reads Fishing State Checker for channel and loot status. It opens stopped. Preserved vision mode is available under **Advanced options**.

## Highlights

- **Fishing** includes audio calibration, a custom reference library, adjustable timing, and optional inventory and session stops.
- **Stats / Tracker** supports live catch receipts, saved history imports, session notes and timelines, daily and area reports, and CSV export.
- **Catch map** reads artwork from your installed client. **Fish finder** opens available zone maps. Catch pins use saved coordinates.
- **Timer / Shutdown** keeps optional logout and Windows shutdown controls separate. PC shutdown is off by default.

## Download and run

1. Download **Angloroth-v2.0.1-windows-x64.zip**, extract the complete **Angloroth** folder, and open **Angloroth.exe**. Python is not required.
2. Open **Setup** and choose **Install all 3 addons**. If Better Fishing and Speedy AutoLoot are already compatible, choose **Update Fishing State Checker only**.
3. Restart WoW after addon installation. In **Keybindings → Better Fishing → Cast and Interact**, set the key selected in Angloroth (default **U**). **Prepare fishing preset** is available for optional setup through WoW chat.
4. Enable Auto Loot and sound effects. Keep the Fishing State Checker strip visible and select the sound output WoW uses. Focus WoW at your fishing spot and press **F8**. Use **F9** or **Escape** to stop.

Choose the named Windows ZIP. GitHub's automatic source archives contain the distribution page. A SHA-256 checksum is available alongside the ZIP. [Better Fishing](https://www.curseforge.com/wow/addons/better-fishing) · [Speedy AutoLoot](https://www.curseforge.com/wow/addons/speedyautoloot)

## Updating and privacy

Keep your previous installation as a backup. Close both copies and copy your own **data** folder into the new installation to retain settings, totals and tracker history. Shared packages contain no personal settings, history, logs or game artwork. The app makes no automatic uploads.

Similar sounds from other apps or nearby anglers can affect bite detection. Use **Test audio** to check your sound output without game input. Automatic play can violate the game's rules and lead to account penalties.
